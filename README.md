# 📈 Indian Share Market Predictor

A Machine Learning based web application that predicts Indian stock market trends and prices using historical stock market data.

---

## 📌 Project Overview

This project predicts stock prices using Machine Learning algorithms and visualizes market trends for better analysis.

The project includes:
- Data Collection
- Data Cleaning
- Data Visualization
- Machine Learning Model
- Stock Price Prediction
- Django Web Application

---

## 🚀 Features

✅ Predict Indian Stock Prices  
✅ Interactive Web Interface  
✅ Historical Stock Data Analysis  
✅ Data Visualization Charts  
✅ Machine Learning Prediction Model  
✅ Real-time User Input Prediction  

---

⚙️ Installation
1️⃣ Clone Repository
git clone https://github.com/krishakbari07/indian-share-market-predictor.git
2️⃣ Move into Project Folder
cd indian-share-market-predictor
3️⃣ Create Virtual Environment
python -m venv .venv
4️⃣ Activate Virtual Environment
Windows
.venv\Scripts\activate
5️⃣ Install Requirements
pip install -r requirements.txt
6️⃣ Run Django Server
python manage.py runserver
